# 🎭 Discord Role Bot

Бот для выдачи и снятия ролей + управление доступом к этим командам.

## Команды

### Выдача / снятие ролей
| Команда | Описание | Кто может |
|---------|----------|-----------|
| `/give_role` | Выдать роль пользователю | Роли с доступом + админы |
| `/remove_role` | Забрать роль | Роли с доступом + админы |

### Управление доступом (только админы)
| Команда | Описание |
|---------|----------|
| `/add_access` | Выдать роли доступ к `/give_role` и `/remove_role` |
| `/remove_access` | Забрать доступ |
| `/list_access` | Показать, у кого есть доступ |

### Остальное
| Команда | Описание |
|---------|----------|
| `/my_roles` | Мои роли |
| `/user_roles` | Роли другого человека |
| `/sync` | Синхронизировать команды (админы) |

## Как выдать доступ

1. Администратор пишет:
```
/add_access role:@Модератор
```
2. Теперь все, у кого есть роль `@Модератор`, могут использовать `/give_role` и `/remove_role`.

Список сохраняется в файл `allowed_roles.json` и не сбрасывается при перезапуске.

## Установка

1. `pip install -r requirements.txt`
2. Создай `.env`:
```env
DISCORD_TOKEN=твой_токен
```
3. В Developer Portal включи **SERVER MEMBERS INTENT**
4. Права бота: `Manage Roles`, `Send Messages`, `Embed Links`
5. Роль бота должна быть **выше** тех ролей, которые он будет выдавать
6. `python bot.py`

Если команды не появляются — используй `/sync` или укажи `GUILD_ID` в `bot.py`.
